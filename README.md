# 🇪🇬 Tourism Egyptian

A modern and interactive single-page landing page designed to showcase the beauty and civilization of Egypt, tailored for tourists and visitors.

## ✨ Features

- **Responsive Design:** Works seamlessly on desktop, tablet, and mobile devices.
- **Interactive Interface:** Custom-built navigation and smooth user experience.
- **Smooth Scrolling:** Features custom `NiceScroll` integration with a tailored color scheme.
- **Interactive Testimonials/Elders:** Dynamic sliding/fading client section.
- **Stylish UI/UX:** Clean design using modern frameworks and crimson/orange accents.

## 🛠️ Tech Stack

- **HTML5:** Semantic and accessible structure.
- **CSS3:** Custom styles and modern layout techniques.
- **JavaScript (ES6):** Interactive features and DOM manipulation.
- **Libraries & CDNs:**
  - [Normalize.css](https://necolas.github.io/normalize.css/)
  - [Bootstrap 5](https://getbootstrap.com/)
  - [Font Awesome Icons](https://fontawesome.com/)
  - [jQuery & NiceScroll](https://cdnjs.com/)
